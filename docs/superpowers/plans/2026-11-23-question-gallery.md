# 问题画廊 Question Gallery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 705 个对话里的 1,296 条人类提问提取成标准问题，去重合并、按主题分模块，做成可浏览可复制的 `#/questions` 画廊页。

**Architecture:** 三段式管道，纯逻辑与 I/O 分离：`tools/questions-lib.mjs` 放全部纯函数（可单测，不碰磁盘），`tools/questions.mjs` 只做 CLI 与文件读写。提取靠 24 个只读子代理并行读切片、各写一份 `qwork/part-NN.json`；再跑一次聚类得到 `qwork/modules.json`；`--merge` 按表确定性分配模块并生成 `web/data/questions.json`；前端在既有 app.js 里新增两个视图路由，复用现有样式与复制/下载助手。

**Tech Stack:** Node 26（`node:test` 内置测试器，零依赖）、vanilla JS/CSS、无框架、无 npm 包。

**Spec:** `docs/superpowers/specs/2026-11-23-question-gallery-design.md`

## Global Constraints

- 零依赖：不得新增 npm 包；测试只用内置 `node:test` + `node:assert/strict`
- 只读数据：`data/` 与 `assets/` 永不修改
- **`tools/build.mjs` 会 `fs.rmSync(web/data, {recursive:true})`**：任何重算不出来的东西（LLM 输出）必须放在 `qwork/`，不能放 `web/data`
- 服务器只绑 `127.0.0.1`，不上传任何数据
- UI 中文（zh-CN），深色默认、浅色为镜像；复用 `web/styles.css` 现有 CSS 变量
- 复用既有助手：`el()`、`copyText()`、`copyButton()`、`$()`、`fmt.num()`、`statePanel()`、`renderTopbar()`；事件名在 `el()` 里必须小写（历史 bug）
- 每个新增/修改的 `.mjs`/`.js` 必须通过 `node --check`
- 路由只加两条：`#/questions`、`#/questions/<module-id>`、`#/c/<convId>/m/<msgId>`
- 提交步骤依赖 Task 0 建立的 git 基线；`assets/`、`data/`、`web/data/`（约 430 MB）不得入库，`qwork/` 必须入库
- 数量口径以 spec 的"数字口径"一节为唯一依据：1,457 人类消息 → 排除 10 空且无附件、151 continue 类 → **1,296 条提取输入**，24 片

## Review Focus

规格暗示、但没有任务的测试覆盖，最容易伤到人的五类输入，按可能性排序。每条都在下方归属任务的步骤里有对应测试：

1. **只有附件的消息**（214 条无文字）——`std` 必须点名附件而不是产出空问题；`orig` 为空时卡片要可读
2. **两条真正不同却高度相似的 `std`**（如"改进 A 类"与"改进 B 类"共享模板句）——去重不得误并
3. **含表格/代码围栏/`<antArtifact>` 的消息**——digest 文本必须原样保留；画廊 `orig` 以纯文本呈现（不渲染 markdown）
4. **U+2028 行分隔符**（该导出里真实存在）——不得破坏 JSON 解析与复制
5. **零提问的对话**（79 个空对话、切片内最低 30 条）——空模块、`未分类` 兜底、计数为 0 时 UI 不得崩

import test from 'node:test';
import assert from 'node:assert/strict';
import fs from 'node:fs';
import path from 'node:path';
import { execFileSync } from 'node:child_process';

const OUT = 'web/data/qdigest';

test('--digest 产出 24 片，总数与口径一致', () => {
  execFileSync('node', ['tools/questions.mjs', '--digest'], { stdio: 'ignore' });
  const m = JSON.parse(fs.readFileSync(path.join(OUT, 'manifest.json'), 'utf8'));
  assert.equal(m.convs, 705);
  assert.equal(m.chunks, 24);
  assert.equal(m.sliceSize, 30);
  assert.equal(m.msgs, 1296);
  assert.equal(m.candidates.total, 1457);
  assert.equal(m.candidates.excludedEmptyNoAttachment, 10);
  assert.equal(m.candidates.excludedContinueLike, 151);
  assert.equal(m.files.length, 24);
  assert.equal(m.files[0], 'part-00.json');
  assert.equal(m.files[23], 'part-23.json');

test('切片内容自洽：对话总数等于 705，附件片段不超过 200 字', () => {
  const files = fs.readdirSync(OUT).filter((f) => f.startsWith('part-'));
  let convs = 0;
  let msgs = 0;
  for (const f of files) {
    const p = JSON.parse(fs.readFileSync(path.join(OUT, f), 'utf8'));
    assert.ok(Number.isInteger(p.chunk));
    convs += p.convs.length;
    for (const c of p.convs) {
      assert.ok(!('blocks' in c) && !('toolResults' in c));
      for (const mm of c.msgs) {
        msgs++;
        for (const a of mm.atts) assert.ok(a.snippet.length <= 201);
      }
    }
  }
  assert.equal(convs, 705);
  assert.equal(msgs, 1296);
});

test('空对话与零提问对话不会破坏切片', () => {
  const p = JSON.parse(fs.readFileSync(path.join(OUT, 'part-00.json'), 'utf8'));
  const empty = p.convs.filter((c) => c.msgs.length === 0);
  assert.ok(empty.length >= 0);
  for (const c of empty) assert.ok(typeof c.convId === 'string' && c.convId.length > 0);
});
